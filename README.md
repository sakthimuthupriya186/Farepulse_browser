# 🚀 Interactive Personal Portfolio Website

A clean, modern, and responsive single-page web portfolio built with pure HTML, CSS, and JavaScript. Hosted effortlessly using GitHub Pages.

---

## 🌟 Key Features

* **⚡ All-in-One Architecture:** Single file layout containing inline CSS styles and interactive JavaScript scripts.
* **📱 Fully Responsive Design:** Compatible across all device screens (Mobile, Tablet, Desktop).
* **🎨 Interactive Visual Elements:**
  * Animated hover cards for project showcases.
  * Real-time user click tracking counter.
  * Functional Contact Form with interactive JavaScript notifications.
  * Skill proficiency indicator bars.
* **📌 Sticky Navigation:** Smooth scrolling top navigation menu.

---

## 🛠️ Built With

* **HTML5:** Semantic structure and page sections.
* **CSS3:** Custom styles, Flexbox layout, smooth gradients, and keyframe transitions.
* **JavaScript (ES6):** DOM manipulation, event listeners, and live UI interactions.
